Content Insights<br>

2.The web client in the context of web server refers to device in front of the user which runs web server software to connect to the web server at the request of the user.<br>
3.The Internet was designed to be decentralized. When your files are stored in a cloud, it means that they are stored on a server somewhere.<br>
4.Native Apps are designed for specific OSs. It is coded using programming languages that requires compiling. They are usually more expensive to build.<br>
5.Web Apps are cheaper to build and maintain, accessible to everyone within a web browser. They don’t work offline. No one checks web apps’ security issues.v
6.The browser manufacturers follow the World Wide Web Consortium (W3C) specifications.  <br>
7.Web apps cannot access any of the hardware on the device where they are running. Native apps have the advantage of accessing hardware on the device where they are located. <br>

2.WordPress is open source because this way the source code can be inspected and modified.<br>
3.Files that make up a WordPress website are stored on a server owned by hosting companies.<br>
4.SSL creates an encrypted link between a web server and a web browser. They are necessary for keeping the information transmission secure and they are easy to install.<br>
5.Updating your WordPress version is a common good practice, either automatically or manually.<br>
6.Use a highly vetted secure and updated theme for your website. This will keep your website away from vulnerabilities.<br>
7.Before updating your theme: <br>
Make a full backup of your site<br>
Read the release notes<br>
