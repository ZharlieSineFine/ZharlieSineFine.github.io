Content Insights
1.When web server software runs on web server hardware, and the system is maintained by a company who will sell you some space on it, that is referred to as a web host or hosting.
2.The web client in the context of web server refers to device in front of the user which runs web server software to connect to the web server at the request of the user.
3.The Internet was designed to be decentralized. When your files are stored in a cloud, it means that they are stored on a server somewhere.
4.Native Apps are designed for specific OSs. It is coded using programming languages that requires compiling. They are usually more expensive to build.
5.Web Apps are cheaper to build and maintain, accessible to everyone within a web browser. They don’t work offline. No one checks web apps’ security issues.
6.The browser manufacturers follow the World Wide Web Consortium (W3C) specifications.  
7.Web apps cannot access any of the hardware on the device where they are running. Native apps have the advantage of accessing hardware on the device where they are located.
